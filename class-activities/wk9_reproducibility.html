Week 9 Exercises - Is It Really There?

Anxiety, extroversion, and a result that depends on who you sampled

NoteOverview

About 55 minutes, split across today’s lecture · Pairs · 🧰 R (tidyverse, rio, here, janitor, datawizard)

Do one part, then we go back to the slides.

  • Part A: Build it and look (~15 min): clean real survey data, fit the additive model, and guess whether the lines are parallel.
  • Part B: Test it (~15 min): fit the interaction, center, and decide what you can conclude.
  • Part C: Your sample, someone else’s file (~25 min): draw your own sample, render, then try to reproduce another pair’s analysis.

By the end you should be able to:

  • Fit and interpret an interaction between two continuous predictors
  • Explain what centering changes in an interaction model, and what it doesn’t
  • Report a null interaction without “marginally significant” or probing it anyway
  • Tell the difference between a result that is reproducible (same data, same code), robust (different defensible choices) and replicable (a new sample)
WarningBefore you start
  1. Run this once in the console: install.packages(c("janitor", "datawizard")). If you already had datawizard and later get could not find function "row_sums", your copy is too old: reinstall it.
  2. No names anywhere in your document: not the title, not author:, not in comments. In Part C another pair receives your file without knowing whose it is.

The study

These are real responses to the Depression Anxiety Stress Scales (DASS-42), collected through the free online version at openpsychometrics.org. The full file has about 40,000 people. You will work with a random sample of 400.

Variables What they are
q1a … q42a DASS items, rated 1–4 in this file (1 = “did not apply to me at all”, 4 = “applied to me very much”)
tipi1 … tipi10 Ten-Item Personality Inventory, a short Big Five measure, rated 1–7
vcl1 … vcl16 “Check the words you know.” vcl6, vcl9 and vcl12 are not real words

The question: anxiety and depression go together. Is that link stronger or weaker depending on how extroverted someone is?

Set up (5 min)

  1. Download the data into the data folder of your PSYC 640 R Project.

    • DASS survey data (.csv, 20 MB)
    • DASS codebook from openpsychometrics (.txt)

  2. New Quarto document, Week 9 - Is It Really There?, saved as week9_reproducibility.qmd. Delete the author: line.

Part A — Build it and look (15 min)

A1. Validity check

Anyone who says they know the definition of a word that doesn’t exist probably isn’t reading carefully. Remove them.

valid <- dass %>%
  filter(vcl6 == 0, vcl9 == 0, vcl12 == 0)

## OR

valid <- dass %>% 
  mutate(
    check = vcl6 + vcl9 + vcl12
  ) %>% 
  fitler(check < 1)

nrow(valid)
TipCheck yourself

400 → 346. 54 people checked at least one fake word.

A2. Score the scales

  • Depression: items 3, 5, 10, 13, 16, 17, 21, 24, 26, 31, 34, 37, 38, 42
  • Anxiety: items 2, 4, 7, 9, 15, 19, 20, 23, 25, 28, 30, 36, 40, 41
  • Extroversion: the mean of tipi1 (“Extroverted, enthusiastic”) and reverse-scored tipi6 (“Reserved, quiet”). On a 1–7 scale, the reverse of x is 8 − x.

Before you compute extroversion, look at what’s actually in those two columns.

valid %>% count(tipi1)
valid %>% count(tipi6)

Q1. The scale runs 1–7. What are the 0s, and what should you do with them?

TipShow the scoring code

A 0 means the person skipped the item. It is missing, not “very low.” Recode it to NA before computing anything, then drop anyone without an extroversion score.

Use the row_sums() function from datawizard (https://easystats.github.io/datawizard/reference/row_means.html)

final <- valid %>%
  mutate(
    dass_dep = row_sums(., select = c(q3a, q5a, q10a, q13a, q16a, q17a, q21a,
                                      q24a, q26a, q31a, q34a, q37a, q38a, q42a),
                        min_valid = 0.8),
    dass_anx = row_sums(., select = c(q2a, q4a, q7a, q9a, q15a, q19a, q20a,
                                      q23a, q25a, q28a, q30a, q36a, q40a, q41a),
                        min_valid = 0.8),
    tipi1 = na_if(tipi1, 0),
    tipi6 = na_if(tipi6, 0),
    extra = (tipi1 + (8 - tipi6)) / 2
  ) %>%
  filter(!is.na(extra))
TipCheck yourself

n = 337. If you have 346, the 0s are still in, and some people have an extroversion score of 0.5 on a 1–7 scale.

  mutate(ex_grp = if_else(extra >= median(extra),

Part B — Test it (15 min)

NoteFrom groups to a continuum

In lecture, the moderator was a group (tutor: yes/no), and the interaction was how much the study slope changed between the two groups. Here the moderator is extroversion, which runs from 1 to 7.

The model is the same, y ~ x * z. The only change is how you read the interaction coefficient: how much the anxiety slope changes for each 1-point increase in extroversion. The median split in A4 was a picture of that, chopped into two groups.

B1. The interaction

mod_int <- lm(dass_dep ~ dass_anx * extra, data = final)
summary(mod_int)

anova(mod_add, mod_int)
Note🖱️ In JAMOVI

In Model Builder, Ctrl/Cmd-click anxiety and extroversion, then use the arrow dropdown ▾ → Interaction. To compare models, put the main effects in Block 1 and the interaction in Block 2, and open Model Comparisons.

ΔR² = .004, F(1, 333) = 2.76, p = .097

B2. Center

final <- final %>%
  mutate(anx_c   = dass_anx - mean(dass_anx),
         extra_c = extra - mean(extra))

mod_int_c <- lm(dass_dep ~ anx_c * extra_c, data = final)
summary(mod_int_c)
Note🖱️ In JAMOVI

Data → Compute: anx_c = anxiety - VMEAN(anxiety) and extra_c = extroversion - VMEAN(extroversion). Refit with the centered variables.

❓ Questions for the debrief

  1. How many files rendered on the first try? What broke most often?
  2. When the numbers didn’t match the paragraph, what was missing from the paragraph?
  3. Some pairs got p < .05. Did they do anything wrong?
  4. Imagine every pair’s result was a separate published study, and only the significant ones got published. What would that literature say about extroversion?
NoteThe point of Part C

Reproducible means same data and same code give the same numbers. That’s what rendering someone else’s file tested.

Robust means different defensible choices (dropping the TIPI 0s or not, centering or not) lead to the same conclusion. That’s what checking their numbers against their paragraph tested.

Replicable means a new sample gives the same conclusion. That’s what the tally tested. A single study with n ≈ 340 can come out either way on a small effect, which is why one significant result isn’t the end of the story, and one null result isn’t either.
